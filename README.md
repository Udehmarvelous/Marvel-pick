# MarvelPeak — Nigerian Study Platform

> A fully offline, single-file study game built for Nigerian secondary school students preparing for **JAMB (UTME)** and **WAEC/SSCE** examinations.

---

## Overview

EduPeak is a professional quiz and study platform packed into a single HTML file — no server, no installation, no internet required (except for the optional AI Practice mode). Students can log in, choose a subject and topic, practice with real past questions from 1999 to 2025, track their progress, and compete on a leaderboard.

## How to Use

### 1. Open the App

Double-click `EduPeak_StudyApp.html` in any modern browser (Chrome, Firefox, Edge, Safari). No installation needed.

### 2. Login or Register

- Use the demo account (`demo` / `demo1234`) to explore
- Or click **"Create one free"** to register your own account

### 3. Start Practising

1. Click **Practice** in the navigation bar
2. Choose your **Exam Type** (JAMB, WAEC, Practice, or AI)
3. Select a **Subject**
4. Choose a **Topic** (or All Topics)
5. Set difficulty, question count, timer, and year range
6. Click **Begin Practice Session**

### 4. During the Quiz

- Read the question carefully
- Click your chosen option to select it
- Click **Submit Answer** to confirm
- Read the explanation, then click **Next Question**
- Use **Skip** if you want to move on without answering

### 5. Review Results

After the last question, your results screen shows:

- Score and percentage
- Correct / Wrong / Skipped counts
- XP earned
- Answer-by-answer review for the first 12 questions

## Technical Details

| Property          | Value                                         |
| ----------------- | --------------------------------------------- |
| File type         | Single HTML file                              |
| File size         | ~153 KB                                       |
| Dependencies      | Google Fonts (Syne, JetBrains Mono) via CDN   |
| Storage           | Browser `localStorage`                        |
| Internet required | No (except AI Practice mode and Google Fonts) |
| Browser support   | Chrome, Firefox, Edge, Safari (ES2020+)       |
| Lines of code     | ~1,660                                        |

### AI Practice Mode

When using AI Practice, the app calls the **Anthropic Claude API** to generate fresh questions on demand. This requires an active internet connection. All other modes work fully offline.

### Data Persistence

All user data (accounts, XP, scores, activity) is saved to `localStorage` in the browser. Data persists across sessions as long as the browser cache is not cleared. Data is stored per-browser and is not synced across devices.
